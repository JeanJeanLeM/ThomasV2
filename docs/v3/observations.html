Observations · brouillon

Un constat, distinct du travail.

Une observation note ce que l’agriculteur a vu. Une tâche note ce qu’il a fait. Les deux peuvent tenir dans le même message. L’orchestrateur en fait deux cartes.

Cette définition reprend la table observations de la V2, puis ajoute les colonnes validées pour la V3.

Ce que le message peut porter

Le prompt reconnaît un constat obligatoire, et le sujet sur lequel il porte.

SujetExemples
CulturePucerons sur les tomates. Mildiou sur les vignes. Floraison des courgettes. Fruits mûrs.
MatérielLe tracteur fait un bruit étrange. Relié à materials si le nom est reconnu.
BâtimentLa serre 1 ne s’ouvre plus. Relié à la parcelle si elle est reconnue.
PersonneUn membre cité, relié à farm_members / profiles si reconnu.

Le constat n’est pas seulement un problème. La croissance et la maturation sont des observations : floraison, levée, germination, fruits mûrs. La gravité par défaut est moyen, et basse pour un constat neutre comme une floraison.

L’écran de carte affiche parfois Faible, Moyen, Élevé et Critique. Les valeurs enregistrées restent basse, moyen et haute.

Photo, position, voix

Une photo ou une position GPS jointes au message sont une ligne de attachments (ex-action_attachments), reliée par observation_id. Le type est image ou location. L’image garde le fichier et son adresse publique. La position garde la latitude, la longitude, et l’adresse si elle est connue. La voix, elle, passe par audio_file_id sur l’observation. Les autres fichiers de ferme (PDF, factures, analyses) suivent le cahier Documents — une photo d’observation reste une pièce jointe d’action, pas un document de bibliothèque, sauf si l’agriculteur demande de l’archiver.

Dans le chat

En V3, les colonnes forment la carte résumé. L’écriture attend la confirmation, comme pour le temps.

Hier j’ai vu des pucerons sur les tomates de la serre 1, début de ligne.

  1. Thomas reconnaît une observation, catégorie ravageurs, gravité moyen si rien d’autre n’est dit.
  2. Le constat est « pucerons ». La culture est « tomates ». Le titre proposé est « Pucerons Tomates ».
  3. La date dite est hier → observed_on. Sans date dite, ce serait aujourd’hui.
  4. Il retrouve la parcelle Serre 1. Précision « début de ligne ». Sans sous-parcelle dite, ce champ reste vide.
  5. Après confirmation, la ligne est visible dans les observations. La supprimer la masque, is_active passe à faux.

Les courgettes fleurissent, et j’ai désherbé la planche 3 pendant une heure.

Deux cartes. La floraison est une observation de croissance. Le désherbage est une tâche. Chacune se confirme seule.

Le tracteur Kubota fait un bruit étrange depuis ce matin.

Observation, catégorie degats_materiel. Matériel reconnu si présent dans materials. Date dite : aujourd’hui.
