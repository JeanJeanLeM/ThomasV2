Navigation & chrome · décidé

Inventaire SSOT : coquille, écrans, zones, contrôles, ouvertures.

Cette page est la source de vérité pour le chrome et les surfaces UI retenues dans le CDC. Elle ne remplace pas les pages domaine (règles métier) ni Équivalences (où tél vs ordi). Elle dit quoi est à l’écran, comment on y arrive, et ce qui ouvre quoi.

Règle de lecture. Statut décidé = déjà tranché dans le CDC. « À préciser » seulement si le produit laisse vraiment un trou. Matrice tél/ordi = équivalences — pas de Gantt mobile, pas de dessin carte mobile, pas de fiche ITK éditable mobile.
Règle d’ouverture. Chat = écriture principale (carte confirmable). Dashboard = approfondir / corriger / cocher. Bascule barre = même app, pas une autre. Erreurs nommées → erreurs.html.

Layout ordinateur Chat + Dashboard · décidé

Décidé C · tiroir chat repliable. Sur ordi : le dashboard occupe la zone principale. Le chat est un tiroir latéral repliable (pas une colonne fixe par défaut) — ouvert / fermé depuis la barre. Agent-natif : le tiroir s’ouvre assez large pour écrire et confirmer des cartes ; on peut le replier pour gagner de la place sur Gantt / carte.
RègleComportement
Défaut ordiDashboard plein + chat en tiroir (ouvert ou fermé selon contexte / dernier état)
Tiroir chatRepliable depuis la barre (« Chat ») ; pas de colonne fixe permanente comme défaut
NavColonne gauche collapsible (inchangée)
TélInchangé : bascule exclusive plein chat ↔ plein dashboard ; nav tiroir
Non retenusA (bascule exclusive ordi) · B (split côte à côte permanent)
