Tests · brouillon (cœur vibe-coding)

Ce qui doit passer avant de coder à l’aveugle.

Trois couches complémentaires. Le bench IA tranche Jev / LLM. Les scripts déterministes verrouillent le modèle de données et les règles d’écriture. Le bot UI parcourt les écrans. Chaque cas cite l’objet métier et l’événement d’erreur attendu s’il échoue. Météo et conseil : hors catalogue premier lot.

Cohérence. Un test qui contredit Fondation (harness, mémoire, confirmation) ou Données (colonnes, écriture) est faux — on corrige le test ou le cahier, pas l’implémentation « au feeling ».
