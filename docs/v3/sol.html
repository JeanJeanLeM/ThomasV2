Sol · décidé

Analyses complètes. On enregistre ce qui est fourni.

Une analyse de sol labo est souvent un rapport dense : texture, calcaire, pH, matière organique, CEC, majeurs, oligo-éléments, parfois ETM ou conductivité. Thomas V3 accepte tous ces postes. Aucun n’est obligatoire : on ne stocke que ce qui figure sur le bulletin (ou ce que l’agriculteur dicte). On n’invente pas une valeur absente. On n’en déduit pas encore un bilan fertilisation simulé.

Règle d’extraction. PDF / photo / saisie chat → carte confirmable avec tous les postes détectés (valeur + unité + méthode si lisible). Postes absents du bulletin = absents de la fiche. Commentaires / classes du labo (« faible », « élevé ») sont conservés à part, sans les transformer en chiffres.

Modèle de données · décidé

Analyse de sol

soil_analyses (nom à figer en migration)
  • Métadonnées : parcelle, dates, labo, référence, profondeur, document_id
  • results : liste (ou JSON) de postes — { code, label?, value, unit, method?, class?, confidence? }
  • Pas de colonnes figées pour chaque oligo : le catalogue ci-dessus est le vocabulaire produit ; le stockage reste extensible
  • raw_text / extrait OCR optionnel pour audit
  • is_active, auteur, timestamps
S1 · Complet mais creux. Le produit connaît le catalogue large ; une fiche peut n’avoir que 3 postes. L’UI affiche d’abord les postes renseignés, puis un repli « Tous les postes possibles » pour saisie manuelle.
S2 · Méthode & unité. Toujours conserver l’unité du bulletin. Pour P (et assimilés multi-méthodes), conserver la méthode.
S3 · Pas d’invention. Extraction : uniquement ce qui est lu / dit. Ambiguïté de lecture → champ marqué + confirmation.

Carte chat / dashboard

  1. Message ou fichier → classification analyse de sol.
  2. Carte : métadonnées + liste des postes extraits (groupés : texture, pH, MO, CEC, majeurs, oligos, autres).
  3. L’agriculteur corrige, ajoute un poste manquant, ou retire une valeur mal lue.
  4. Confirmation → enregistrement + document lié.

Sur ordinateur, la fiche Sol montre le détail complet et l’historique des analyses de la parcelle. Téléphone : résumé des postes clés + lien ouvrir le PDF.

Recherche & filtres · décidé. Sur la fiche analyse (tél + ordi) : champ de recherche par libellé de poste (pH, CEC, Cu…) et chips de filtre par groupe (Tous, Texture, pH, MO, CEC, Majeurs, Oligos, Autres/ETM). Les groupes sans résultat sont masqués. Compteur « N postes visibles ».

Besoins NPK · décidé

Outil séparé de type règle de trois : pour une culture, à partir de besoins NPK issus d’une source fiable documentée, ordre de grandeur pour la surface. Ce n’est pas un plan de fertilisation complet, et ce n’est pas une réécriture automatique des commentaires du labo.

L’outil peut s’appuyer sur les postes P / K (et N si pertinent) présents sur l’analyse, en respectant la méthode. S’il manque un poste requis, Thomas le dit.

Hors premier lot

Apports. On n’enregistre pas encore un apport d’engrais comme simulation d’effet sur le sol.
Bilans. Pas de bilan azoté ni de bilan humique calculés par Thomas.
Alertes ETM / seuils réglementaires. Stockage oui ; diagnostic réglementaire automatisé plus tard.
Comparaison multi-années avancée / cartographie intra-parcelle. Plus tard.
