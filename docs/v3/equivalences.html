Équivalences mobile ↔ desktop · décidé

Même produit. Capacités selon la surface.

Une seule web app, une seule coquille. Téléphone et ordinateur ne dupliquent pas deux logiciels : ils exposent les mêmes données avec des capacités adaptées. Cette page est la matrice de référence pour le cahier et le futur Figma.

Règle. Tout ce qui exige largeur, densité ou dessin fin = ordi. Le téléphone enregistre, consulte et confirme via le chat (et listes / calendrier semaine). L’agent est l’éditeur riche mobile.
