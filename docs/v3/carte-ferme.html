Carte de la ferme · décidé

Dessiner, ajouter et modifier les formes. Modifier la ferme.

Le plan / carte de la ferme est le dashboard spatial de l’exploitation : fond satellite (ou orthophoto), formes des parcelles, fiche et emprise de la ferme. Il vit dans la coquille partagée (Chat ↔ Dashboard + nav collapsible). Ce n’est pas un logiciel carto séparé, ni un clone Desktop V2.

Objectif. L’agriculteur voit sa ferme sur une image réelle, y dessine ses parcelles, corrige les contours, et met à jour les infos de la ferme (nom, adresse, centrage). L’agent peut ouvrir la carte, proposer un mode dessin, ou une fiche à confirmer.

Deux niveaux d’objets

NiveauObjetRôle spatialFiche
Ferme farms Centre carte (map_center) et, optionnellement, emprise / limite (geometry). Sert à cadrer le fond satellite. Nom, adresse, code postal, éventuellement pays / commune. Modifiable depuis Compte et depuis la carte.
Parcelle plots Polygone métier (geometry). Vérité spatiale dès qu’il est renseigné. Nom (obligatoire), type, dimensions, actif / inactif. Peut exister sans géométrie (liste seule).
Règle. Les sous-parcelles (surface_units / planches) ne sont pas dessinées sur le satellite en v1. Leur géométrie utile reste la disposition du plan de culture — voir Planification.

Fond carte

  1. À l’ouverture, Thomas centre sur farms.map_center s’il existe ; sinon géocode adresse / code postal ; sinon demande un point (« Pose le centre de ta ferme sur la carte »).
  2. Fond : tuiles satellite ou orthophoto (fournisseur à brancher en technique ; le cahier exige seulement un fond image réel du sol, pas un schéma abstrait).
  3. Contrôles : zoom molette / pinch, pan, bouton « Recentrer sur la ferme », bascule éventuelle satellite / labels (routes) si le fournisseur le permet.
  4. Après modification de l’adresse ou du centre ferme : proposition de recentrer (pas de saut brutal sans prévenir si l’utilisateur a déjà pan).

Dessiner une forme

Mode explicite dans la barre d’outils carte. Un seul mode actif à la fois.

OutilGesteRésultat
Polygone Clic = sommet ; double-clic ou « Terminer » ferme ; « Annuler point » retire le dernier sommet ; Échap annule le tracé. Polygone fermé ≥ 3 sommets.
Rectangle Clic-glisser ou deux coins opposés. Rectangle aligné (rotation optionnelle en édition).
Cercle / ellipse Centre + rayon (ou boîte englobante). Forme approximée stockée en polygone densifié ou géométrie cercle selon le stock technique.

Pendant le tracé : aperçu en pointillés, sommets visibles, surface provisoire affichée. Impossible de terminer une forme auto-intersectante : message court, correction des sommets.

Ajouter une forme → parcelle

À la fermeture d’une forme valide, un panneau (ou carte chat si l’intention vient du chat) propose :

  1. Créer une nouvelle parcelle — nom (obligatoire), type (serre, plein champ…), reprise proposée de surface / longueur / largeur depuis la géométrie.
  2. Lier à une parcelle existante — liste des parcelles sans géométrie (ou toutes, avec avertissement d’écrasement).
  3. Annuler — la forme disparaît, rien n’est écrit.

Autres entrées vers le même flux : liste Parcelles → « Dessiner sur la carte » (parcelle pré-sélectionnée) ; chat « Ajoute une serre sur la carte » → dashboard carte en mode dessin + carte de confirmation à la fin.

Ajoute une serre plastique Serre 3 et dessine-la sur le plan.

Thomas peut d’abord créer la fiche (nom + type) puis ouvrir le mode dessin lié à cette parcelle, ou inverser : dessiner d’abord, puis nommer. Les deux ordres sont valides ; la confirmation écrit une seule fois.

Modifier la ferme

Accessible depuis le panneau carte « Modifier la ferme », depuis Compte / fiche exploitation, ou via le chat.

ChampEffet
NomAffiché dans la barre (sélecteur multi-fermes).
Adresse, code postalGéocodage proposé → nouveau map_center ; l’utilisateur confirme le recentrage.
Centre cartePoint posé sur la carte (« Définir le centre ») ou coordonnées.
Emprise / limiteOutil « Limite ferme » : dessiner ou modifier un polygone d’emprise (farms.geometry). Visuel distinct des parcelles (contour tireté). Optionnel.

Change l’adresse de la ferme et recentre la carte.

Carte de réglage chat → écrit farms → propose « Recentrer maintenant ». Multi-fermes : chaque ferme a sa propre carte ; la bascule de ferme dans la barre recharge fond + formes.

Droits : propriétaire / responsable modifient la ferme et les géométries ; les autres rôles consultent (sauf politique plus fine ultérieure).

Mesures

  • Surface (m² et ha) et périmètre (m) calculés dès qu’une géométrie existe.
  • À la création ou après édition : proposition « Mettre à jour longueur / largeur / surface de la fiche » — l’agriculteur accepte ou garde les valeurs saisies à la main.
  • Les mesures ne remplacent pas la disposition en planches du plan de culture.

Décidé (C1–C6)

C1 · Carte dans Thomas. Un registre Dashboard de la coquille V3, fond satellite / ortho, pas d’app carto parallèle.
C2 · Dessiner. Polygone, rectangle, cercle ; tracé guidé ; pas d’auto-intersection.
C3 · Ajouter. Forme fermée → créer parcelle ou lier à une existante ; nom obligatoire à la création.
C4 · Modifier formes. Sommets, translation, suppression géométrie ou parcelle ; mesures proposées à la fiche.
C5 · Modifier la ferme. Fiche (nom, adresse, CP, centre) + emprise optionnelle ; recentrage confirmé ; multi-fermes = une carte chacune.
C6 · Surfaces. Ordi = dessin / édition. Tél = consultation / sélection / fiches. Agent ouvre et orchestre ; confirmation selon règles V3.
