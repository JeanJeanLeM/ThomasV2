Web app

Carte produit

Thomas V3 est une web app pour toutes les filières végétales — une seule UI. Le chat est l’interface. Chaque écriture passe une carte confirmable. Le dashboard approfondit, surtout sur ordinateur.

La V2 reste le produit en service. Ce dossier fixe les décisions, les scénarios et ce qui reste au bench. Une section décidé ne se réécrit pas au fil de la conversation. Figma : archiver le fichier actuel ; rebuild après stabilisation de ce cahier — pas maintenant.

Méthode · décidé. On ne porte ni le code ni la logique des outils existants (Thomas Desktop V2, Basile Pro, mobile V2). On s’en sert pour écrire un cahier comparable (objets métier, besoins, douleurs), puis on recode une seule app V3 : logique unique, style unique, parcours simplifiés, agent-natif. Captures et démos = matière à cahier, pas à cloner.
Décidé A · coquille ordi unique. Tous les écrans ordinateur partagent la barre Chat ↔ Dashboard + nav V3. Vérité visuelle : ce cahier docs/v3 (+ futur Figma hors frames « z ref »).
Décidé · approfondissement 2026-11-17. Mémoire en 6 couches · toolcalling visible (bulles d’activité) · une UI toutes filières · catalogue d’événements d’erreur · matrice mobile↔desktop · Documents (facile / complexe) · Itinéraires & coûts · Tests/Données renforcés. Météo / conseil : non précisés.
Décidé · inventaire navigation 2026-11-17. Page Navigation & chrome : coquille tél/ordi, chaque surface retenue (zones, contrôles, états, ce qui ouvre quoi), alignée équivalences et erreurs.
